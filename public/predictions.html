How it was scored

2,441NEAR hackathon repos read by the screener
1best-fit track per project, so 39 different podium spots
195finalists (top 15 per track) judged by Claude Fable 5.2
/145Tech 30 · Innovation 25 · Execution 20 · UI 10 · NEAR 30 · Track fit 30

Pass 1: screener

  • Every repo read: README, file tree, 1-2 key files
  • Scored on the same /145 criteria
  • Placed in one best-fit track among the tracks it entered
  • Flags for mocked claims, forks, and code from before 1 Nov

Round 2: AI judge

  • One Claude Fable 5.2 judge per track, same prompt for every track
  • Read the README and 2 to 4 key source files per repo
  • Checked README claims against the code: real or mocked
  • Flagged work from before the window and commits after it
  • Repos read through the GitHub API only: nothing cloned, installed or run

Limits

  • Only each track's top 15 was judged in depth by Fable
  • On-chain transactions and live demos were not checked
  • Close scores (2 points or less) are within noise
  • Official judging may weigh things differently
